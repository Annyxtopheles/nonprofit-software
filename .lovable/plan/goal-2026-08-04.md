- **Honeypot conflict**: the hidden bot-trap field is currently named `company`, which now collides with a real field. It gets renamed to a neutral hidden name (`website`) in both the form and the `newsletter-subscribe` validation, so real company values are never rejected as spam.

- **GHL payload**: send `firstName`, `lastName`, `phone`, and `companyName` so the contact in the sub-location is fully populated, not just an email.
